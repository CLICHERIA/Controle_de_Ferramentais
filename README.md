# Sistema de Registro e Controle de Ferramentais

ASPECTOS GERAIS 

Estabelecer o registro e o controle de ferramentais, de modo a garantir que tenhamos precisão sobre os dados de chegada do referido ferramental à Sovel, sua duração de utilização, e momento específico para a substituição do mesmo.
Estes dados garantirão o database para o estabelecimento dos QR codes.
